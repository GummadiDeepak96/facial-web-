## 🔄 How It Works

```
User Action          →  Component State   →  API Call        →  Dashboard
─────────────────────────────────────────────────────────────────────────
Select "Employee"    →  userType changed →  POST /auth/...  →  /employee/...
Enter credentials    →  formData updated →  login called    →  Redirect
Click "Login"        →  loading = true   →  token stored    →  Dashboard
```
